1. Input images

Drag and drop image files or choose them manually.

Brightness, contrast, sharpness
no image selected

Changes the selected image only; the original file is not modified. The adjusted image is used in the Result, saved files and Compose figure. Scale bar, letters and text are drawn on top and are not affected.

Original/source scale value

This value is the calibration source. The output bar length is computed from it. Example: if the original image is 1 µm and you set the output to 2 µm, the final bar becomes 2× longer automatically. Units: nm, µm, mm, m, Å. A wrong auto read can be corrected per file in Calibration on the right.

Scale label

Example: 0.5 µm

You can also drag the scale bar or the panel letter on the Result preview to place it anywhere on one image.

Font
Times New Roman / system

Point sizes match Word when the figure is printed at this width (8.5 cm ≈ one journal column, 17 cm ≈ full page width).

The font applies to the unit, the panel letter and free text. An imported font file is stored only in your browser. System fonts are used if installed on this computer.

Panel letter
upper-left corner

Write any text. A single letter such as a, (a), C), а or (А) continues automatically on the next images (b, c… or б, в… following GOST, without ё з й о ч ъ ы ь); any other text is used as written on every image. Override the letter of one image in Scale label and panel letter on this image; add free text with + Text in Text, shapes and arrows.

Each processed image is saved as its own file, for example image-1_clean.png. TIFF, PDF and SVG hold the same lossless image at 300 dpi. On Chrome/Edge desktop you can select an output folder once and save all files directly into it.

1. Panels

Processed images from the Clean & annotate tab.

Untick a panel to leave it out. Reorder with ↑ ↓, or click one panel in the preview and then another to swap them.

Layout

One number (e.g. 2) gives the same count in every row; a pattern (e.g. 3,2 or 1,2) sets each row. Equal row height keeps every image whole and fills the width. Equal cells fits each image inside identical cells. Images are never cropped or stretched, so scale bars stay exact.

Drag a panel in the preview to move it, or drag the corner handles of the selected panel to resize it (aspect ratio kept). This switches to Free. Panels snap to edges, centre and spacing; hold Alt to place freely.

Ctrl + click panels to select several
Table
Header sides

Drag a panel in the preview, or a row of the panel list, onto any cell; or click a panel and then a cell. Cells may stay empty. The number beside a header merges it over the next cells. Header text: <b>, <i>, H_{2}O, x^{2}, Greek as \alpha, \beta, \Omega; Enter for a new line.

Size

8.5 cm ≈ one journal column, 17 cm ≈ full page width. The saved file carries this size, so Word inserts it at the right width.

Labels

Letter format, size and highlight come from Panel letter in the Clean tab.

Scale label and letter per panel
no panel selected

Click a panel on the preview (or its name in the list) to edit it. Changes are shared with the Clean tab.

Text, shapes and arrows

Drawn on the whole figure, on top of the panels (e.g. arrows pointing between panels or a frame around a region). Click an object on the preview to select it, drag to move, drag handles to resize; Delete removes it. Text sizes are true points in the final figure.

1. EDS input

AZtec Word reports (.docx) or loose map images.

Each report is a separate group with its own maps, scale and settings. Click a group to edit it.

Images inside a .docx are extracted in document order and named from their captions (e.g. Fe Kα1, Electron Image 1, Map Sum Spectrum). Loose images are named from the file name (e.g. Fe_Ka1.png). Old .doc files must be re-saved as .docx.

Selected image

If the element was not recognised, type it here (e.g. Cr or Cr Kα1). Its content from Element content then appears on this map.

Clean-up (all images)

If a label or bar is missed, turn on Erase area tool and drag a box over it on any image in the preview. The same area is erased on every image (they share the field of view), filled with the surrounding background.

The same crop is applied to the electron image and every map, so they stay aligned. Trimming does not resample, so calibration stays exact.

Element labels

Drag a label, content value or scale bar on the preview to move it on that map; double-click puts it back. Changing a Position resets the moved ones. The font family comes from the Font section in tab 1.

Element content
no values

Values come from quantification tables in the Word report or, if there are none, from text recognition of the spectrum image. Check and correct them in the box. Color, bold and highlight follow Element labels.

Scale bar
not calibrated

Maps share the field of view of the electron image, so one calibration covers all of them (scaled by pixel size if the map resolution differs). Bar style, color and unit language follow tab 1.

Figure layout

A spectrum, if included, is placed full width below the maps.
